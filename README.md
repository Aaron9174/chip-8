# chip-8

## Description
This repo will contain a Chip-8 processor emulator. Contained within this repo will be needed documentation of the chip-8 architecture, various chip-8 ROMs used for testing obtained online, a disassembler, and the emulator itself.

## The Goal
The primary goal is to accomplish three things:
1) The emulator shall be capable of disassembling a Chip-8 ROM and producing source assembly listings
2) The emulator shall be capable of executing a Chip-8 ROM without crashing
3) The emulator shall be able to accept user input via keyboard and produce a graphical display
